XKNX Toolkit is a Python library suite for working with KNX automation system files. It provides typed, well-tested packages for reading ETS project exports, product archives, security keyrings, and the underlying XML data models.

## Packages

<Cards>
  <Card title="xknx-models" description="KNX XML schema bindings and version detection" href="/docs/models" />
  <Card title="xknx-product" description="Read and validate .knxprod archives" href="/docs/product" />
  <Card title="xknx-project" description="Project state management for KNX installations" href="/docs/project" />
  <Card title="xknx-keys" description="Parse and serialize KNX keyring XML" href="/docs/keys" />
</Cards>

## Installation

Install the individual packages you need via pip:

```bash
pip install xknx-models
pip install xknx-product
pip install xknx-project
pip install xknx-keys
```
