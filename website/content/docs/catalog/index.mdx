`xknx-catalog` ingests `.knxprod` archives into a local SQLite database and exposes the data through a FastAPI REST API. It lets you browse manufacturers, hardware items, and application programs across all your ingested product files. Depends on `xknx-models` and `xknx-product`.

## Installation

```bash
pip install xknx-catalog
```

## Starting the server

```bash
python -m xknxmono.catalog
# or
uvicorn xknxmono.catalog.app:app --reload
```

The API is served at `http://localhost:8000` by default. Interactive docs are available at `/docs`.

## Ingesting product files

Upload a `.knxprod` file via the REST API:

```bash
curl -X POST http://localhost:8000/upload \
  -F "file=@device.knxprod"
```

The server extracts manufacturer data, hardware items, and application programs and stores them in the catalog database.

## Browsing the catalog

Once product files are ingested, use the hardware browser in the sidebar or query the REST API directly:

```bash
# List all manufacturers
curl http://localhost:8000/manufacturers

# List hardware for a manufacturer
curl http://localhost:8000/hardware?manufacturer_id=M-0001

# Get application details for a hardware item
curl http://localhost:8000/hardware/M-0001_H-001/application
```

## Database

The catalog uses a SQLite database (`catalog.db`) located next to the package data directory by default. Override the path with the `DATABASE_URL` environment variable:

```bash
DATABASE_URL=sqlite:////data/my-catalog.db python -m xknxmono.catalog
```
