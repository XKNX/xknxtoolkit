XKNX Toolkit is a Python library suite for working with KNX automation system files. It provides typed, well-tested packages for reading ETS project exports, product archives, security keyrings, and the underlying XML data models.

## Packages

<Cards>
  <Card title="xknx-models" description="Every version of KNX's data model, unified into one representation." href="/docs/models" />
  <Card title="xknx-product" description="Everything inside a KNX product archive, ready to explore." href="/docs/product" />
  <Card title="xknx-project" description="Inspect and edit KNX project files with a clean, typed API." href="/docs/project" />
  <Card title="xknx-keys" description="Read, write, and manage your KNX Secure keyring." href="/docs/keys" />
</Cards>

## Installation

Install the individual packages you need via pip:

```bash
pip install xknx-models
pip install xknx-product
pip install xknx-project
pip install xknx-keys
```
