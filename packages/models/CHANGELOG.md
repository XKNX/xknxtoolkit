## [0.1.0] - 2025-05-24

### Added

- Initial release of `xknx-models`.
- KNX XML schema bindings generated by xsdata for versions 10–14 and 20–23.
- `detect_version()` helper to extract schema version from raw XML bytes.
- `load_xml()` helper to parse XML bytes into a fully typed `Knx` object.
- `serialize_xml()` helper to round-trip a `Knx` object back to XML bytes.
- `get_model_class()` to retrieve the version-specific `Knx` dataclass.
- `SUPPORTED_VERSIONS` frozenset constant.
- `VersionError` exception for unknown or unsupported version strings.
